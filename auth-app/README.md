# Auth App - Login & Signup Component

A modern React component for authentication with a clean, responsive design using TailwindCSS.

## Features

- **Toggle between Login and Signup**: Single component that switches between authentication modes
- **Responsive Design**: Works on all screen sizes with a centered layout
- **Modern UI**: Clean, professional design with smooth transitions and hover effects
- **Form Validation**: Basic HTML5 validation for required fields
- **Success Feedback**: Shows success message after form submission
- **TailwindCSS**: Styled using TailwindCSS via CDN

## Login Mode
- Email field
- Password field
- Sign In button

## Signup Mode
- Full Name field
- Email field
- Password field
- Create Account button

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to the local development URL (usually `http://localhost:5173`)

## Technologies Used

- React 18
- Vite
- TailwindCSS (via CDN)
- Modern JavaScript (ES6+)
